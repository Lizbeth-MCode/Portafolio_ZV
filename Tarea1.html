📌 Enunciado

Reto: Clasifica ventas como alta o baja usando las siguientes reglas:

Alta si la venta es mayor o igual a 200.
Baja si es menor a 200.

🧠 Definición de datos

ventas = [90, 220, 180, 310, 50]

Podemos observar las cantidades de las ventas, donde cada valor está en un índice correspondiente.

lo que seria visto como:

ventas = [0], [1], [2], [3], [4]


Lo siguiente seria recorrer esa lista:

⚙️ Lógica aplicada


Con for indicamos que la variable venta recorrera toda la lista de las ventas e imprimirá sus valores

for venta in ventas: print("Venta obtenida de: $", venta) if venta >= 200: print("venta alta") else: print("venta baja")

Con if logramos clasificar cada valor en la categoria Alta o Baja segun corresponda.
